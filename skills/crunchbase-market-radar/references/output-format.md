# Market Radar output

Start with the as-of date, agreed market/ICP, two date windows, and whether the universe is market-wide, a named account book, or an agreed bounded comparison. State retrieved and reported unique counts. Keep facts, calculated labels, optional Crunchbase predictions, and seller hypotheses distinct.

Use a compact table of segment, computed label, current/prior rounds, company count, growth share, and explanation. Link segment and organization names only to returned canonical URLs; do not invent URLs. Show unknown cells as `—` with the legend “— indicates no value was returned for that field.” Include insufficient-evidence and small segments in the file and summarize their counts in chat. If fewer than three peers qualify, explain why no direction comparison can be made; offer a scope change for acceptance, never silently broaden.

Say “segments to investigate” and “segments to reconsider under this rule.” Seller fit is an optional hypothesis with a question to validate. A predicted raise is not cash received, approved budget, or readiness to buy. Note relevant disagreement with the latest dated Crunchbase market insight. Do not treat a prediction explanation as independently observed fact.

The helper writes `result.json`, `segments.csv`, and `handoff.json`. Link the actual artifacts. The handoff records proposed segment UUIDs and the already accepted scope for a prospecting request; creating it does not authorize discovery, saving lists, or outreach. Reuse accepted filters downstream and ask only for unresolved material choices. Territory results retain memberships and, when the user accepts the documented balanced policy, an exclusive assignment or Other. Explain that assignment policy with its coverage.

State material limitations: unclassified segments, missing growth/founding data, incomplete optional prediction coverage, unknown financing amounts, and overlapping memberships. Distinguish missing records from evidence an event did not happen. See `references/output-contract.md` for the common evidence principles; its private-market framing does not restrict an explicitly agreed GTM universe to private companies.
